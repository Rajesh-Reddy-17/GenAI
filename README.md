# 🤖 GenAI

An AI-powered web application that allows users to chat with local LLMs using Ollama and generate AI images using the Hugging Face Inference API. Built with HTML, CSS, JavaScript, Node.js, and Express.

---

## 🚀 Features

- 💬 AI Chat Interface
- 🖼️ AI Image Generation
- ⚡ Fast Response with Ollama
- 📂 Chat History
- 🌙 Modern & Responsive UI
- 📱 Mobile Friendly Design
- 🔄 Real-time AI Responses
- 🎨 Clean User Experience

---

## 🛠️ Tech Stack

### Frontend
- HTML5
- CSS3
- JavaScript

### Backend
- Node.js
- Express.js

### AI
- Ollama
- Hugging Face Inference API

## 📦 APIs Used
